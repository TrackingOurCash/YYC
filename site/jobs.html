How the numbers work

  • Daily tracking started –. The City's list shows no posting date, so a posting's date is the first morning it was seen.
  • Postings from before then were rebuilt from Internet Archive copies of the careers page, which caught it a few times a month. Their date is the first archived copy that lists them, so postings already open when the first copy was taken all land in that month, and postings open only between copies are missed. These are marked "Archived".
  • Why some position types are "not known": the number of positions and whether they're permanent or temporary are only on each posting's own page, and the City takes that page down when the posting closes. The collector reads it while a posting is open, but for postings rebuilt from the archive the page usually wasn't saved. Each of those counts as one position of unknown type. Untick "Include type not known" to leave them out.
  • Yearly pay is the pay range midpoint × positions: base pay only, not benefits. When a posting's own pay isn't available, it uses the range for the same title on the City's compensation disclosure list for that year, then the pay on another posting with the same title. Postings with no match count as $0, so totals are a floor. Hourly pay is annualised from weekly hours (35 if not stated), and temporary positions count at the yearly rate even if they last a few months.
  • A posting is a job the City intends to fill, not a confirmed hire, and most fill existing jobs that someone left rather than adding new ones. The City doesn't say which postings are new positions.
