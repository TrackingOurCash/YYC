Tracking Our Cash / Calgary

Sources

Every number on this site comes from something the City of Calgary publishes. This page lists each source, what we take from it, and where our copy lives so you can check it yourself.

How the data is collected

A scheduled job on GitHub runs every morning at 7:00 Calgary time (6:00 in winter). It downloads each source below, saves the result as plain CSV or JSON files in the project's GitHub repository, and rebuilds the site. Every change is a commit, so the repository's history shows what each source said on each day. The code for each step is linked in the tables.
